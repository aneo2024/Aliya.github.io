Git 清除敏感提交笔记

1. 取消暂存所有文件（仅取消 Git 追踪标记，不删除本地文件）

  • 作用：将所有已暂存（staged）的文件取消暂存，从 Git 暂存区移除，保留工作区本地文件
  • 配合 .gitignore 使用，可让忽略规则生效

2. 查看当前 Git 状态

  • 作用：查看文件暂存状态、分支提交差异（如本地领先远程 N 个提交）

3. 彻底删除本地敏感提交

命令解析

  • HEAD~6：定位到当前最新提交往前数第 6 个版本
  • --hard：强制重置，同步将代码文件 + 提交记录完全恢复到目标版本
  • 效果：彻底丢弃目标版本之后的 6 个提交，包含在这 6 次提交中的所有密钥、敏感文件、配置会一并清除

核心原理

该命令会回滚分支的版本指针，同时重置工作区和暂存区，直接抹除后续 6 次提交的所有记录，是清除已提交敏感信息最直接的方式。
