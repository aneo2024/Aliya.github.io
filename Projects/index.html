🚀 项目一：多模态 AI Agent 系统

项目简介

一个基于 Vue 3 + FastAPI 的多模态 AI Agent 系统，支持图像识别、数据分析、图表生成等功能。项目采用前后端分离架构，通过 SSE 流式输出提供实时反馈。

技术栈

前端

  • Vue 3 Composition API
  • Vite 6.0
  • Pinia 状态管理
  • Element Plus
  • SSE 流式通信

后端

  • FastAPI
  • Microsoft AutoGen (Multi-Agent)
  • MCP (Model Context Protocol)
  • YOLO 视觉模型
  • Python 沙箱执行

核心亮点

  • 🔄 Multi-Agent 协作：VisionAgent、MetricValidator、Critic、Reporter 多角色协商
  • 📊 数据可视化：Python 代码执行 + 自动图表生成
  • 🎯 Function Calling：MCP 协议集成，支持热插拔工具
  • ⚡ 流式输出：SSE 实时推送，支持进度反馈
  • 🛡️ 安全执行：代码沙箱隔离 + 3 次自动修复机制

🎓 项目二：极客教育视频平台

项目简介

一个在线教育视频平台，支持课程发布、视频播放、用户购买等功能。采用 Go 微服务架构，前后端分离设计。

技术栈

前端

  • React 19
  • Ant Design
  • React Router
  • Axios
  • ReactPlayer

后端

  • Go + Gin (API 网关)
  • Go + gRPC (业务逻辑层)
  • MySQL + sqlx
  • 阿里云 OSS
  • JWT 认证

核心亮点

  • 🏗️ 双层微服务：API 网关 + gRPC 业务逻辑分离
  • 🎬 播放鉴权：JWT Token + 购买状态校验 + OSS 预签名 URL
  • 📤 分片上传：gRPC 流式 RPC 实现大文件可靠上传
  • 🔒 安全设计：防盗链、时效 URL、禁止直接下载
  • ⚡ 性能优化：gRPC 长连接复用、数据库连接池
